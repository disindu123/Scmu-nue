# Sanghabodhi College Nittambuwa — Media Unit Portfolio

A fully separated, responsive HTML/CSS/JS portfolio website based on the supplied design direction and upgraded for a professional school media-unit presentation.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design, typography and animations
- `script.js` — navigation, scroll reveal, counters, portfolio filters, particles and enquiry system
- `assets/profile.jpg` — supplied profile image kept from the uploaded project
- `assets/db` — original project asset retained

## Main features
- Premium white/navy visual system
- Manrope + Playfair Display + Space Mono typography
- Animated top ticker and footer marquee
- Floating media icons and orbiting hero graphics
- Animated particles and scan-line effect
- Responsive mobile navigation
- Scroll-reveal animations
- Animated hero counters
- Filterable portfolio grid
- Team/committee section
- Professional enquiry form with generated inquiry IDs
- Mailto-based enquiry submission
- Back-to-top control
- Reduced-motion accessibility support
